# 画面遷移

すべて架空のサンプルです。画面間のリンクは動作しますが、API操作は未提供の表示に留めます。

| パス                           | 画面                                     |
| ------------------------------ | ---------------------------------------- |
| `/`                            | 企業の概要と面談サンプル                 |
| `/login`                       | ログイン未提供の説明とサンプルへの入口   |
| `/jobs`                        | 求人一覧                                 |
| `/jobs/demo`                   | 求人と質問の設定（保存不可）             |
| `/interviews`                  | 面談一覧                                 |
| `/interviews/invite`           | 招待発行未提供と候補者サンプルへのリンク |
| `/interviews/sample-a/report`  | 候補者Aの架空記録と発言根拠              |
| `/interviews/sample-b/report`  | 候補者Bの架空記録と発言根拠              |
| `/settings/members`            | メンバー・権限サンプル                   |
| `/candidate/demo`              | 候補者向けの案内                         |
| `/candidate/demo/check`        | 職種・やってみたいことの選択と利用前確認 |
| `/candidate/demo/conversation` | 4問のダミー回答入力と回答の編集          |
| `/candidate/demo/summary`      | 回答ごとの要約、質問のやり直し、補足     |
| `/candidate/demo/complete`     | 画面確認の完了                           |

企業の主導線は「概要 → 求人・質問設定 → 招待 → 候補者サンプル」。記録の確認は「面談一覧 → 記録 → 発言根拠」です。候補者は「ご案内 → 仕事の希望・利用前の確認 → 4つの質問に回答 → 要約の確認・訂正・補足 → 完了」と進めます。要約から、選んだ質問だけやり直せます。

候補者の確認チェックはブラウザ内だけの状態です。直接URLにアクセスでき、正式な同意や認証の代用にはなりません。保存操作、ダウンロード、招待、ログイン、音声操作は成功扱いにせず、利用不可のメッセージを表示します。候補者の回答はReactの状態として画面内だけで保持し、DB・ブラウザストレージへの保存や外部送信はしません。再読み込み、企業側画面への移動、最初からのやり直しで入力は消えます。マイク許可も求めません。未回答のまま要約画面を開いても、回答や確認済み状態を自動で補いません。

React Routerの履歴ベースのルーティングを使います。WorkersのStatic AssetsはSPAフォールバックを設定し、直接アクセスとリロードを扱います。別の静的配信先を使う場合も、画面URLは `index.html` へフォールバックし、`/api` はHTMLへフォールバックさせないでください。

API未接続のためTanStack QueryやSupabase SDKはまだ追加していません。接続を実装する段階で構成案に沿って導入します。

候補者側の詳細は [候補者のダミー対話](candidate-demo.md) を参照してください。企業側の架空記録は独立したサンプルで、候補者側の入力とは同期しません。
