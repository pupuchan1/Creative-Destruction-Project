# 画面遷移

すべて架空のサンプルです。画面間のリンクは動作しますが、API操作は未提供の表示に留めます。

| パス                           | 画面                                     |
| ------------------------------ | ---------------------------------------- |
| `/`                            | 企業の概要と面談サンプル                 |
| `/login`                       | ログイン未提供の説明とサンプルへの入口   |
| `/jobs`                        | 求人一覧                                 |
| `/jobs/demo`                   | 求人と質問の設定（保存不可）             |
| `/interviews`                  | 面談一覧                                 |
| `/interviews/invite`           | 招待発行未提供と候補者サンプルへのリンク |
| `/interviews/sample-a/report`  | 候補者Aの架空記録と発言根拠              |
| `/interviews/sample-b/report`  | 候補者Bの架空記録と発言根拠              |
| `/settings/members`            | メンバー・権限サンプル                   |
| `/candidate/demo`              | 候補者向けの案内                         |
| `/candidate/demo/check`        | 説明確認と同意欄のサンプル               |
| `/candidate/demo/conversation` | 音声未提供と完了画面へのリンク           |
| `/candidate/demo/complete`     | 画面確認の完了                           |

企業の主導線は「概要 → 求人・質問設定 → 招待 → 候補者サンプル」。記録の確認は「面談一覧 → 記録 → 発言根拠」です。候補者は「ご案内 → 利用前の確認 → 対話 → 完了」と進めます。

候補者の確認チェックはブラウザ内だけの状態です。直接URLにアクセスでき、正式な同意や認証の代用にはなりません。保存操作、ダウンロード、招待、ログイン、音声操作は成功扱いにせず、利用不可のメッセージを表示します。入力は保存・送信せず、マイク許可も求めません。

React Routerの履歴ベースのルーティングを使います。WorkersのStatic AssetsはSPAフォールバックを設定し、直接アクセスとリロードを扱います。別の静的配信先を使う場合も、画面URLは `index.html` へフォールバックし、`/api` はHTMLへフォールバックさせないでください。

API未接続のためTanStack QueryやSupabase SDKはまだ追加していません。接続を実装する段階で構成案に沿って導入します。
