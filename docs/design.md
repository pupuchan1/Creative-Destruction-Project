## 配色と形状

| 用途                                             | 色        |
| ------------------------------------------------ | --------- |
| 背景                                             | `#FFFFFF` |
| 主要ボタン、選択中のナビゲーション、数字、リンク | `#1447E6` |
| 本文、主要な境界線、ロゴ                         | `#111111` |
| 補足の文字                                       | `#626B7B` |
| 情報の背景                                       | `#F4F7FF` |
| 補助の境界線                                     | `#D9DEE8` |

白の余白と黒の細い罫線を基本にし、青を操作と見出しのアクセントに使う。カード、入力欄、ボタン、タグは角を丸めず、影による階層付けは避ける。候補者画面の青い球体だけは円形の装飾とし、通話中を示すアニメーションは付けない。

## 全画面への反映

- 企業画面は上部ナビゲーションを共通化。概要の見出し、数字、面談一覧、求人、入力欄、確認記録、メンバー画面を同じトークンで構成する。
- 候補者の案内は見出しと青いビジュアルの2列構成。利用前の確認、対話、完了画面は横幅を抑え、番号と区切り線で進行を示す。
- ログイン画面はブランドの導入と操作パネルを分け、スマートフォンでは縦に並べる。
- 操作不能やAPI未接続の説明は淡い青で表示する。保存、招待、音声処理の成功表示は出さない。
- モバイルの表は補助列を省き、主要な操作リンクを表示する。フォーカス表示、ラベル、画面遷移の構造を維持する。

外部画像、フォント、JavaScriptライブラリは追加しない。青い球体はCSSで描画する。プレビューは `npm run build:preview` で再生成できる。
